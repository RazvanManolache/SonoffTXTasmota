# Download and install the scripts

Open **Actions > Sonoff script package > Run workflow**. Download the successful
run's **Sonoff-TX-Ultimate-scripts** artifact and extract the script ZIP inside it.

Upload `autoexec.be`, `tasmota.be` and `txultimate.be` to your device's Tasmota
filesystem. Tasmota must have Berry and filesystem support enabled; configure the
TX Ultimate GPIO template for your hardware before restarting. See README.md.
`user_config_override.h` is a source-build example, not a device upload.

This workflow produces scripts, not flashable firmware. The pinned host Berry
compiler checks syntax without executing device calls. Tasmota-specific modules,
GPIO behavior, LEDs and relay operation require testing on the actual device.
Keep the source scripts; host-generated bytecode is deliberately not distributed.
